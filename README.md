# 🌊 명조: 워더링 웨이브 — 효율적인 재화 구매 최적화 계산기 웹앱

이 프로젝트는 오픈월드 액션 RPG 게임 **'명조: 워더링 웨이브'** 내에서 유저가 목표로 하는 뽑기 재화 및 유로 재화를 **가장 저렴한 비용(최소 금액)**으로 구매할 수 있는 패키지 및 달빛 상품 조합을 찾아주는 **Gradio 기반의 웹 애플리케이션**입니다.

게임 내 복잡한 1회성 효율 패키지, 초회 2배 보너스, 그리고 단방향 재화 변환 규칙을 컴퓨터 알고리즘(동적 계획법 및 완전 탐색)으로 분석하여 낭비 없는 소비 전략을 제안합니다.

---

## ✨ 핵심 기능

1. **다양한 목표 재화 입력 지원**
   - 단일 유로 재화 계산기에서 벗어나, 유저가 원하는 `별의 소리`, `금빛 파도의 무늬`, `울린 조수의 무늬`, `꿈을 잡는 무늬`, `새겨진 그림자의 무늬` 개수를 각각 독립적으로 입력받습니다.
2. **단방향 재화 변환 메커니즘 반영**
   - 게임 내 규칙(`달빛` ➡️ `별의 소리` ➡️ 각 `무늬` 가치로의 단방향 교환, 반대 방향은 불가)을 정확하게 연산에 반영합니다. (1무늬 = 160 별의 소리 가치로 환산)
3. **1회성 패키지 및 초회 보너스 실시간 반영**
   - 이미 구매하여 상점에서 사라진 1회성 한정 패키지나 초회 달빛 상품을 체크박스로 제외하고 최적의 조합을 계산할 수 있습니다.
4. **동적 계획법(DP) 및 조합 최적화 알고리즘 기반 계산**
   - 상품 총합 구매 가격이 가장 저렴한 조합을 우선 추천합니다.
   - **[업데이트]** 만약 총합 가격이 같은 최적 대안이 여러 개 존재할 경우, 유저에게 재화를 더 많이 주는(초과 획득량이 더 큰) 상품 조합을 스마트하게 채택합니다.
5. **상세한 결과 리포트**
   - 추천 상품 목록 및 총 합계 금액 표기
   - 최종적으로 인게임에서 받게 되는 각 재화별 실제 획득 수량 명시
   - 종합 가치를 별의 소리로 환산한 가성비 지표 제공 (1 별의 소리당 가격)
   - 상품 구조상 목표치보다 얼마나 더 많은 재화가 초과 획득되는지 구체적으로 표기

## 📦 데이터베이스 구성 (상점 상품 정보)

- **1회 제한 패키지 및 초회 상품:** 반역자의 컬렉션 시리즈, TARD-E의 월간 지원, 탐구의 컬렉션 시리즈 및 각 구간별 초회 달빛 상품 (총 13종)
- **상시 반복 구매 상품:** 초회 혜택이 적용되지 않는 상시 달빛 상품 6종
